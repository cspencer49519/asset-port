# TCGShopExpansionMod 0.71 Patch v1.0.49

**TCG Card Shop Simulator 0.71** compatibility patch for **Genobear Real TCG Overhaul** (Tetramon / Pokemon cards).

## Highlights

- **Pack opening** — stacked pack backs, back-then-front flip timing, fan row presentation, correct card aspect ratio throughout the open sequence
- **Shop display case** — Pokemon card fronts toward customers; opaque backs from behind
- **Player deployment** — `Install-TCG071Mods.ps1`, `Verify-TCG071Install.ps1`, install docs

## Requirements

| Component | Version / source |
|-----------|------------------|
| Game | **0.71** (Steam) |
| BepInEx | Nexus mod 27 |
| Add New Cards Mod | Nexus mod 3 |
| More Card Expansions | **1.8.7** (Nexus mod 48) |
| TextureReplacer | Nexus mod 26 |
| Genobear + ArtExpander | `cardart.assets` (~15 GB) |
| This patch | **1.0.49** |

## Install

1. Download **TCG-071-Genobear-1.0.49.zip** from this release.
2. Extract and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Install-TCG071Mods.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
.\scripts\Verify-TCG071Install.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
```

See `docs/INSTALL-071.md` in the zip for full steps.
