# TCGShopExpansionMod 0.71 Patch v1.0.49

**TCG Card Shop Simulator 0.71** compatibility patch for **Genobear Real TCG Overhaul** (Tetramon / Pokemon cards).

## Highlights

- **Pack opening** — stacked pack backs, flip timing, fan row, correct aspect ratio
- **Shop display case** — correct fronts/backs for Pokemon cards
- **Pre-ported sharedassets** — Genobear card frames on 0.71 (no manual asset porting)
- **Install scripts** — PowerShell, CMD, and bash for Windows / Linux / macOS

## Requirements

| Component | Version / source |
|-----------|------------------|
| Game | **0.71** (Steam) |
| BepInEx | Nexus mod 27 |
| Add New Cards Mod | Nexus mod 3 |
| More Card Expansions | **1.8.7** (Nexus mod 48) |
| TextureReplacer | Nexus mod 26 |

| This patch | **1.0.49** |

Recommended: [Configuration Manager](https://www.nexusmods.com/tcgcardshopsimulator/mods/31) for F1 settings.

## Install (summary)

1. Install Nexus mods + Genobear per **`docs/INSTALL-071.md`** (phases 1–3).
2. Extract this zip and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Install-TCG071Mods.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
.\scripts\Verify-TCG071Install.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
```

**Do not** use `-SkipAssets` on a normal install — card frames need the ported `sharedassets0` trio.

Full steps (CMD, bash, troubleshooting): **`docs/INSTALL-071.md`**.
