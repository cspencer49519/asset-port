# TCGShopExpansionMod 0.70.3 Patch v1.2.1

**TCG Card Shop Simulator 0.70.3** compatibility patch for **Genobear Real TCG Overhaul**.

## Highlights

- Thunderstore package on every release: `TCGPatch-TCGShopExpansionMod_0703_Patch-{version}.zip` (flat layout for thunderstore.io under team **TCGPatch**)
- Patch DLL + pre-ported `sharedassets0` trio included in the Thunderstore zip
- Existing installer zips (`TCG-0703-Genobear-*`) unchanged in structure

## Assets

| Asset | Contents |
|-------|----------|
| **TCG-0703-Genobear-1.2.1.zip** (full) | **First-time install** - patch + ported `sharedassets0` trio + install scripts + docs |
| **TCG-0703-Genobear-1.2.1-patch-only.zip** | Patch DLL + scripts + docs (no sharedassets) |
| **TCGPatch-TCGShopExpansionMod_0703_Patch-1.2.1.zip** | Thunderstore package - upload manually to thunderstore.io |

Thunderstore Mod Manager installs the DLL under `BepInEx/plugins`. Copy `Card Shop Simulator_Data/sharedassets0.*` into the game Data folder manually.

## Install

1. Install Nexus mods + Genobear per **`docs/INSTALL-0703.md`** (phases 1-3).
2. From the full release zip:

```powershell
.\scripts\Install-TCG0703Mods.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
.\scripts\Verify-TCG0703Install.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
```

Or open **`docs/START_HERE.md`** inside the zip.
