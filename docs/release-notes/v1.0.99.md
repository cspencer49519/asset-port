# TCGShopExpansionMod 0.71 Patch v1.0.99

**TCG Card Shop Simulator 0.71** compatibility patch for **Genobear Real TCG Overhaul** (Tetramon / Pokemon cards).

## Highlights

- **Pack rip back fixed** — blue Pokemon card back now appears when the pack splits (vanilla behavior)
- **Flip sequence** — faces reveal in order with per-card backs behind; fan row unchanged
- **Root cause** — UI back canvas is backface-culled while face-down; 180° Y rotation faces it toward the camera (scale mirror and 3D mesh paths cannot render at split)

## Install (summary)

1. Install Nexus mods + Genobear per **`docs/INSTALL-071.md`** (phases 1–3).
2. Extract this zip and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Install-TCG071Mods.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
.\scripts\Verify-TCG071Install.ps1 -GamePath "D:\Steam\steamapps\common\TCG Card Shop Simulator"
```

Full steps (CMD, bash, troubleshooting): **`docs/INSTALL-071.md`**.
