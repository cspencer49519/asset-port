# Ported sharedassets0 (optional Nexus file)

These three files are the **pre-ported** Genobear-compatible card-frame assets for **TCG Card Shop Simulator 0.70.3**.

## Install (manual)

1. Close the game.
2. Go to your game folder (Steam → Manage → Browse local files).
3. Back up existing files in `Card Shop Simulator_Data/`:

   - `sharedassets0.assets`
   - `sharedassets0.assets.resS`
   - `sharedassets0.resource`

4. Extract this archive into the **game root** (same folder as `Card Shop Simulator.exe`) so the three files land under `Card Shop Simulator_Data/`.

Vortex / mod managers usually **cannot** install these Data files correctly — manual copy is expected.

## Notes

- Required if you use Genobear-style card frames on 0.70.3.
- **Do not** use Genobear's raw 0.62 `sharedassets0` on 0.70.3.
- The patch DLL is a separate main file on this Nexus page.
